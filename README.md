## 🚀 Featured Projects

### 1. FinSight AI — Financial Intelligence Platform

An AI-powered financial intelligence platform designed to transform unstructured financial documents into structured information and actionable financial insights.

**Key Contributions & Features**

- OCR-based receipt and invoice text extraction.
- Machine learning classification into 7 budget categories.
- TF-IDF feature extraction and Multinomial Naive Bayes classification.
- Financial analytics and reporting capabilities.
- PostgreSQL database integration using Supabase.
- React and TypeScript-based application architecture.

**Machine Learning Result:** 80% accuracy on a 175-record evaluation dataset.

**Technology Stack:**
`Python` `Scikit-learn` `OCR` `TF-IDF` `React` `TypeScript` `Flask` `PostgreSQL` `Supabase`
